# Store Submission Checklist

## App Store Connect
- App name: Overcomers Global Network.
- Bundle ID: `com.overcomers.globalnetwork.app`.
- Category: Lifestyle or Religion/Education where available.
- Privacy URL: `https://overcomersglobalnetwork.com/privacy`.
- Support URL: `https://overcomersglobalnetwork.com/support`.
- Marketing URL: `https://overcomersglobalnetwork.com/marketing`.
- Sign-in required: yes.
- Include reviewer credentials from the secure credential source.
- iPad support is disabled for 1.0, so iPad screenshots are not required.

## Google Play
- Package name: `com.overcomers.globalnetwork.app`.
- Data Safety disclosures should include account info, profile info, photos/videos, chat/prayer content, app activity, device identifiers/push tokens, diagnostics, and location for Evangelism.
- Upload production AAB from EAS or local build output.

## Release Rules
- Do not submit unless `ALLOW_STORE_SUBMISSION=true`.
- Do not include screenshots from stale web mockups.
- Use fresh screenshots from native iOS/Android builds after the final visual pass.
