# Store Screenshots

Use native screenshots from the final app build only.

## iPhone
- Accepted sizes include `1242x2688` or `1284x2778`.
- Recommended set: Home, Media, Give, Chat, Bible, More, Evangelism, Prayer.

## Android
- Use current emulator or physical-device screenshots from the production build.
- Recommended set: Home, Media, Give, Chat, Bible, More, Evangelism.

## Do Not Use
- Old web design-review captures.
- Screenshots where the Home or More globe leaves obvious gaps.
- Screenshots with missing media/prayer/story images.
