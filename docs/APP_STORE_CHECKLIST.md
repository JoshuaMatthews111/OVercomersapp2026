# 24-Hour Submission Checklist

## Must be finished before submission
- App launches without crashing.
- No broken buttons in primary navigation.
- Privacy policy URL ready.
- Support URL ready.
- Demo reviewer account ready.
- Location permission explains evangelism map purpose.
- Bible copyright handled through provider/API; no illegal NIV/AMP text stored.
- Chat has moderation and report/delete controls.
- Private outreach/contact data is protected by auth and RLS.
- App screenshots generated for iPhone and Android.
- App description does not claim features not built yet.

## Version 1.0 MVP Scope
- Home/Watch
- Messages by Series
- Bible reader/provider wrapper
- Mandatory Community Chat
- Prayer Requests
- Evangelism Maps with drill-down/follow-up
- Giving links
- Events
- Profile

## Delay until Version 1.1
- OGN University app integration
- Certificates
- Full offline map packs
- AI follow-up automation
- Advanced analytics exports
